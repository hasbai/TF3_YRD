# 长三角 1950 · 南京—舟山

《狂热运输 3》Windows 地图导入包，61 座城镇、33 个产业。以现代地理、城镇和企业资料制作，保留 1950 年开局。连接长三角的农场、工厂和港口。

**[下载 v0.4.0 地图包](https://github.com/hasbai/TF3_YRD/releases/download/v0.4.0/TF3_YRD_v0.4.0.zip)** · [版本说明与校验文件](https://github.com/hasbai/TF3_YRD/releases/tag/v0.4.0)

## 地图内容

- 覆盖南京、上海、杭州、宁波、舟山主岛及朱家尖。补齐太仓、张家港、嘉定、松江、南汇等地，并增加苏中、苏南、杭嘉湖与浙西县城。
- 山地高差为旧版的 3.5 倍，最高约 617 米；平原保留建设空间。
- 河流采用 OpenStreetMap 的自然河流节点，保留黄浦江、钱塘江、甬江等曲线；删除运河、太浦河、望虞河等人工直渠，缺段不补画。
- 道路可使用游戏自带的 Main Connections 功能生成。舟山保持海岛。
- 产业采用现今企业或品牌加类型，点位参考现有厂区、农场和园区；远洋原油平台位于地图东缘。
- 主要城市按 2020 年七普全市常住人口统一缩尺：上海约 311 人、苏州约 159 人、杭州约 149 人、南京约 116 人。

![长三角地形与城市预览](docs/preview.png)

现实范围约 380 × 380 km，压缩到游戏内 28.672 × 28.672 km。地理内容顺时针旋转 10°。

## 开始游玩

完整解压 ZIP，按 `YRD_1950/使用说明.md` 将高度图、生态蒙版和城市产业 Lua 导入原生地图编辑器。无需模组或 Python。

Steam 用户目录常见位置：`…\Steam\userdata\<账号编号>\3493540\local`。包内 `使用说明.md` 提供详细步骤。

新建地图时将 **Names / 名字集设为 Chinese / 中国**，游戏显示语言选择 **简体中文**，使后续生成的名称使用中文。

参数：温带、Gigantomaniac、1:1；高度图最低 **−20 m**、最高 **700 m**、水位 **0 m**。等预览加载完成后点击底部“导入”，再应用生态与城镇产业布局，执行产业名称命令后保存。

## 开局线路

| 玩法 | 线路 |
|---|---|
| 短途蔬菜 | 嘉佑粮蔬农场 → 杭州；一号粮蔬农场 → 句容 |
| 建材 | 船山石灰石矿 → 诺贝尔陶瓷厂 → 杭州、绍兴或嘉兴 |
| 水运 | 太湖渔场 → 湖州；舟山渔场 → 舟山 |

## 数据与验证

地形来自 Mapzen Terrain Tiles，海岸、湖泊和水库来自 Natural Earth，河流来自 © OpenStreetMap contributors（ODbL 1.0）。城市参考现代人口，植被与产业产能按游戏需要配置，地名和企业不按 1950 年复原。

离线检查覆盖 PNG、坐标、点位、静态供需链和海域连通。本版按用户要求只制作地图文件，未安装或运行游戏验收。此前版本的测试范围见 [游戏验收记录](docs/game-validation.md)。
