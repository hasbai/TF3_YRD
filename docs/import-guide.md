# 长三角 1950 地图包

包含地形、生态、城镇产业导入素材。导入后保存为地图；实际验收结果见 `docs/游戏验收.md`。

Steam 用户数据目录常见位置：`…\Steam\userdata\<账号编号>\3493540\local`。也可通过编辑器“打开文件夹”找到实际目录。

## 自行导入素材

| 项目 | 设置 |
|---|---|
| 气候 | 温带 / Temperate |
| 地图大小 | Gigantomaniac，需开启实验地图尺寸 |
| 比例 | 1:1 |
| 游戏范围 | 28.672 × 28.672 km |
| 高度图 | 7169 × 7169，16 位单通道 PNG |
| 最低 / 最高高度 | **−20 m / 700 m** |
| 水位 | **0 m** |
| 开始年份 | **1950** |
| 地名资料 | 现代地理与名称 |
| Names / 名字集 | **Chinese / 中国** |
| 游戏显示语言 | **简体中文 / zh_CN** |
| 城镇 / 产业 | {{TOWNS}} / {{INDUSTRIES}} |

1. 关闭游戏，在用户数据目录的 `settings.lua` 中将 `experimentalMapFeatures` 改为 `true`，保存后重启。已开启时跳过。
2. 游戏显示语言选 **简体中文**。新建温带、Gigantomaniac、1:1、1950 年的编辑器地图，**Names / 名字集选 Chinese / 中国**。
3. 将包内 `heightmaps/`、`biomes/`、`towns_industries/` 的文件复制到用户数据目录下的同名文件夹。
4. 在高度图导入页选择 `YRD_1950_7169.png`，填写 **最低 −20、最高 700、水位 0**，关闭“保留资产”。移开输入焦点，等预览加载完成，再点击底部 **Import / 导入**。导入后确认实际地图出现河湖和海面。
5. 在 **Biomes / 生态蒙版** 页选择 `YRD_biomes.png`，点击 **Apply / 应用**。Mountains 和 Rivers 两栏留空。
6. 在 **Towns & Industries → Import** 页选择 `YRD_1950.lua`，关闭“保留城市”和“保留产业”，导入布局。
7. 按下文方法执行 `docs/恢复产业名称.txt`。道路按需使用游戏的 **Main Connections / 主连接** 功能生成，检查跨江与海岛连接方案后应用。
8. 检查地图，选择 **Save Map / 保存地图**。从该地图开始游戏，年份选 1950。

名字集原生值为 `::/names/china/china.names`。它决定后续自动生成的名称；已有的中文城镇名不能替代该设置。保存地图会保留名字集。布局 Lua 不修改名字集或界面语言。

游戏日志中的 `Replacing terrain` 表示已执行地形替换，`Importing biomes` 表示已执行生态应用。日志位于 `crash_dump/stdout.txt`。

## 应用产业名称

在主菜单“设置 → 高级 → 调试选项”开启 Debug Mode，再进入编辑器。打开游戏控制台，按键以键盘设置中的 Console 为准，通常为 Esc 下方的反引号键。

复制对应 TXT 的完整一行命令，粘贴并按 Enter。控制台不提供 `dofile`。执行后关闭菜单回到地图，等待回调：

- 名称：`YRD: renamed 33, failed 0, already correct 0`；重复运行时为 `YRD: all 33 industry names already match`。

名称命令按产业资源类型和最终位置匹配。它将随机名称改为 CSV 中列出的现今企业和品牌名称。产业编号保留在 CSV。完成后保存地图。

## 地形与水系

现实范围约 {{REAL_SIDE_KM}} × {{REAL_SIDE_KM}} km，水平压缩约 {{SCALE}} 倍。地理内容顺时针旋转 {{ROTATION}}°，北向见预览箭头。范围包含南京、上海、杭州、宁波、舟山主岛和朱家尖。

高地按 DEM 起伏的约 35% 缩放，为旧版的 3.5 倍，实际最高约 {{MAX_TERRAIN}} m。平原保持低缓，城镇和工厂附近平整。

海岸与湖泊、水库来自 Natural Earth；自然河流采用 OpenStreetMap 中心线，保留原始折线节点，按游戏需要加宽。运河、太浦河、望虞河等人工直渠已删除，缺少数据的河段不补画。太湖保留为独立湖泊。

河床和海底约 −2.5 至 −12 m。沿海检查点在距岸至少 16 m 的水面连通；船舶寻路尚需游玩测试。

植被是地形驱动的设计分布，树群群落区域约占陆地 {{FOREST_PERCENT}}%。灰度 26、77、128 分别对应开阔草地、草地树群、深色草地。该比例不是实际树冠覆盖率。

## 城镇与人口

主要城市采用 2020 年第七次人口普查的全市常住人口，每 8 万参考人口约对应 1 名游戏居民。上海约 311、苏州约 159、杭州约 149、南京约 116 人。县级城镇规模为游戏设计估计，合计预计 {{EST_POP}} 名游戏居民。全市参考人口包含下辖县市，仅用于规模换算。

全图共 {{TOWNS}} 座现代城镇。张家港、德清、建德、上虞、余杭等使用现今名称和中心位置，不再采用历史县治。保留太仓、嘉定、松江和南汇（惠南）等用户指定地区。

## 产业与开局

| 玩法 | 货物链 |
|---|---|
| 短途公路 | 嘉佑粮蔬农场 → 杭州；一号粮蔬农场 → 句容 |
| 建材 | 船山石灰石矿 → 诺贝尔陶瓷厂 → 杭州、绍兴、嘉兴 |
| 林业 | 老山林场 → 大自然德森堡木材加工厂 → 泰州、扬州、南通 |
| 纺织 | 中供棉花原料站 → 一棉纺织厂 → 银德、华利达制衣厂 |
| 重工业 | 永强煤炭供应站 + 高村铁矿 → 马钢钢铁厂 → 柳工机械厂 |
| 液体运输 | 中海油远洋原油输入站 → 中石化高桥炼油厂 → 华星氯碱化工厂 |
| 水运 | 太湖渔场 → 湖州；舟山渔场 → 舟山 |

海上原油平台位于地图东缘约 500 游戏米处，代表外部原油输入。产业按现代企业、厂区和农业基地定位；游戏工厂类型和产能对应货物链。

城市初始各有一项商业需求和工业需求，所需货物均有供应点。可先经营一至两条短途货运链，再扩建干线。

## 文件

- `heightmaps/`、`biomes/`、`towns_industries/`：编辑器导入素材。
- `地图预览.png`、`产业布局预览.png`：离线预览。
- `docs/城市坐标与参数.csv`、`docs/产业坐标与参数.csv`：点位、需求、人口口径和产业编号。
- `docs/恢复产业名称.txt`：一行控制台命令。
- `docs/水系中心线.geojson`：OSM 河道节点、来源 URL、SHA256 和署名，采用 ODbL 1.0。
- `docs/离线检查.json`、`docs/游戏验收.md`：离线检查与实机结果。
- `docs/来源与制作口径.md`：来源、许可和改编口径。
