# 长三角 1950 地图导入包

本包供《狂热运输 3》Windows 版的原生地图编辑器使用，无需安装地图生成 MOD 或 TPF3 Map Studio。包含实际生成的地形、生态蒙版、城市与产业布局；尚未在游戏中导入验收，也不是已保存的游戏地图文件。

## 参数

| 项目 | 设置 |
|---|---|
| 气候 | 温带 / Temperate |
| 地图大小 | Gigantomaniac，实验档最大级别 |
| 比例 | 1:1，地理内容顺时针旋转 {{ROTATION}}°，北向见预览箭头 |
| 游戏范围 | 28.672 × 28.672 km |
| 高度图 | 7169 × 7169，16 位单通道 PNG |
| 导入最低高度 | **−20 m** |
| 导入最高高度 | **240 m** |
| 水位 | **0 m** |
| 开始年份 | **1950**，在游戏的新建/开始游戏设置中选择 |
| 城市 | {{TOWNS}} 座，每城约 19—64 人，合计预计 {{EST_POP}} 人 |
| 产业 | {{INDUSTRIES}} 个点，原版温带产业链 |

最大实验档的 1:2 地图面积略大；本包选同档方图，使长三角的地理形状和城际方向保持一致。它不是 1:2 的高度图，导入时不要换比例。

## Windows 导入步骤

1. 完整解压本包。关闭游戏，在游戏用户数据目录的 `settings.lua` 中将 `experimentalMapFeatures` 改为 `true`，保存后重启。若已经开启，无需再次修改。
2. 新建地图编辑器地图：**温带、Gigantomaniac、1:1、1950 年**。城市和产业初始生成数量设为最少；后面的布局导入会替换它们。
3. 在高度图导入菜单点击“打开文件夹”。将包内 `heightmaps/YRD_1950_7169.png` 复制到游戏的 `heightmaps` 文件夹。将包内 `biomes/YRD_biomes.png` 和 `towns_industries/YRD_1950.lua` 分别复制到用户数据目录下同名文件夹。
4. 选择高度图，填入 **最低 −20、最高 240、水位 0**，关闭 **Keep Assets / 保留资产**，导入。最低/最高值是 PNG 黑白端点的编码范围，不是地形实际最高/最低海拔。
5. 进入 **Biomes / 生态蒙版** 页，在 Biomes 栏选择 `YRD_biomes.png` 并 Apply / 应用。Mountains / Berge 和 Rivers / Flüsse 两栏留空。河湖已写入地形，参考蒙版无需导入。
6. 进入 **Towns & Industries → Import / 城市与产业 → 导入**，选择 `YRD_1950.lua`。首次导入时关闭“保留城市”和“保留产业”，使布局与本包一致。
7. 生成城际道路：先预览连接方案，只保留相邻陆地城市的普通道路。舟山（定海）按海岛城市开局，可通过港口连接宁波、上海和杭州湾；检查并取消自动生成的不合适跨海道路。道路由游戏生成，本包没有预建车站、铁路、港口和车辆。
8. 检查树木、城市和产业，然后选择 **Save Map / 保存地图**。从该地图开始游戏，确认开局年份为 1950。

游戏用户数据目录：Steam 常见位置是 `…\Steam\userdata\<账号编号>\3493540\local`；GOG/Epic 常见位置是 `%APPDATA%\Transport Fever 3`。优先使用编辑器“打开文件夹”找到实际目录。

如果重复导入同一布局，关闭“保留城市/产业”可避免重复点位。城市、产业以及生态导入步骤需要在你的游戏版本中核验。

## 地形与植被

地图以约 {{REAL_SIDE_KM}} × {{REAL_SIDE_KM}} km 的现实范围为底图，地理内容顺时针旋转 {{ROTATION}}°，南京—舟山接近左上—右下对角线。覆盖南京、马鞍山矿区、上海、苏州、无锡、常州、镇江、扬州、泰州、南通、杭州、嘉兴、湖州、绍兴、宁波、宣城和舟山（定海），保留舟山主岛、朱家尖及近海。

水平压缩约 {{SCALE}} 倍。高地按现实 DEM 的约 10% 缩放，保留皖南和浙西山地的形状，实际最高点约 {{MAX_TERRAIN}} m；平原保持低缓地形。城市和工厂周围有小范围平整用地，并按陆水条件调整点位。

长江和主要天然湖泊使用 Natural Earth 地理数据。钱塘江、黄浦江、运河、甬江、曹娥江和新安江使用地理定位后的简化线路补绘，**不是实测河岸**。主航道和运河为游戏适度加宽；太湖与运河增加连通示意，便于形成水运网络。海域按原岸线保留，无额外穿陆开海槽；最终 PNG 中长江口、上海外海、杭州湾、舟山北/东/南侧与甬江口外海在距岸至少 16 m 的海面上连通。海底和河床约 −2.5 至 −12 m，游戏船舶能否通行仍需实测。

植被采用地形驱动的设计分布：皖南、浙西山地多树，平原留开阔农田与草地，城市和产业周边预留建设空间。树木区域约占陆地 {{FOREST_PERCENT}}%，不是 1950 年森林调查的复原。温带 Biome 1 用于生成树群；原版蒙版不能直接控制密林树木密度。

地形底图采用现代高程和岸线。没有把千岛湖等现代水库作为湖面导入；新安江河谷仅作简化处理，未恢复水库蓄水前的测绘地形。这是一张 **1950 年小城开局的现实地理改编地图**。

## 人口缩放

上海、南京、杭州参考 1953 年市区人口，作为 1950 开局的近年代理。苏州另参考 1949 年地方志市区资料，仅用于规模等级，不与其他城市作严格人口比例比较。其他城市按历史城镇特色设计估计，未编造精确历史人口。实数、估计、年份与口径均写在城市 CSV 中。

人口没有按历史人口等比例复制。上海预计约 64 人，南京约 42 人，杭州约 38 人，其余多为 20—35 人。城市使用 `{1, 小规模因子, 1}`，人口因子为 0.20—0.65，依据 TPF3 Map Studio 作者的导入测试；**0.20 是作者测试过的小值，不是已经证实的游戏硬性下限**。实际开局人数及城区大小以游戏生成结果为准。

马鞍山在 1950 年按“马鞍山矿区”小聚落命名，保留矿区聚落的成长空间。

## 产业与起步玩法

| 发展阶段 | 推荐链条 |
|---|---|
| 短途公路开局 | A04 嘉兴农场 → 嘉兴蔬菜；A07 南京农场 → 南京蔬菜 |
| 简单加工 | B01 宜兴黏土 → B02 砖厂 → 常州、镇江、南京 |
| 短途水运 | W01 太湖渔场 → 湖州；W03 杭州湾渔场 → 绍兴、F03 宁波食品加工 |
| 海岛水运 | W04 舟山近海渔场 → 舟山（定海）鱼类需求、F03 宁波食品加工；大陆工具 → 舟山 |
| 林业铁路 | L01 安吉林场 → L04 湖州锯木 → 湖州、嘉兴、苏州、杭州 |
| 沿江重工业 | H01 域外煤炭输入 + H02 马鞍山铁矿 → H03 钢铁点 → 上海机械、宁波食品薄钢板需求 |
| 苏南纺织 | T01 南通棉作 → T02 无锡织布；上海化工染料 + 布 → T03/T04 制衣 |
| 港口与液体运输 | O01 外部原油 → O02 上海炼油 → O03 化工 → 纺织、工具和机械 |
| 消费品加工 | F01 杭州家具 → 宣城；F03 宁波食品 → 宁波商业区 |

城市每座初始只设一项商业需求和一项工业需求。所需货物都有生产点，加工链的必要原料也已布置。农场、林场和矿山扩张仍由游戏决定，没有修改产能或经济规则。

H01 用原版煤矿模拟淮南方向域外煤炭输入；不是在南京附近虚构真实煤矿。O01 海上平台代表外部原油输入，**不是声称 1950 年存在当地海上油田**。H03 马鞍山钢铁为让煤铁链可玩而提前配置，现实马钢建设从 1953 年开始。产业参考区域特色和后续发展方向，不按现代企业逐家复刻；详细例外见产业 CSV。

小城开局客运量少，优先启动一至两条短途货运链，再逐步建设干线。建议关闭产业自动关停，给暂时未连接的远端链条保留发展时间。

## 包内文件

- `heightmaps/`：地形高度图。
- `biomes/`：实际导入的温带生态蒙版。
- `towns_industries/`：一次导入城市和产业的 Lua。
- `地图预览.png`、`产业布局预览.png`：离线预览。
- `docs/城市坐标与参数.csv`、`docs/产业坐标与参数.csv`：位置、人口口径、产业编号与用途。
- `docs/布局数据.json`：布局和补绘水系数据。
- `docs/推荐链条距离.csv`：推荐线路的游戏内直线距离，实际线路长度由建设方案决定。
- `docs/参考蒙版/`：山地、水系参考图；不用于首次导入。
- `docs/离线检查.json`：PNG、坐标、陆水位置、点位间距和产业链检查结果。
- `docs/来源与制作口径.md`：来源链接和制作说明。

已检查文件编码、城市产业数量、边界、陆水位置、点位间距和静态货物链。每个产业都有直接或经过加工/增产链通往城市需求的路径；这不等同于产能与收益平衡测试。**游戏导入、实际树木、产业建筑碰撞、道路生成、船舶寻路与开局经济尚未实测。**
